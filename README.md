# 🐀 Cashflow Online — Крысиные бега с друзьями

Онлайн-версия настольной игры **Cashflow 101** (Роберт Кийосаки) для игры с друзьями в браузере.
Интерфейс на русском, играть можно с компьютера и телефона. Сервер на Node.js (WebSocket), клиент — одна HTML-страница без сборки.

Онлайн версия: https://cashflow-101.onrender.com/

> Проект неофициальный, сделан по правилам из PDF «Cashflow Rules of the Game». Колоды карточек и цифры профессий (кроме Врача) приближённые, не копия настольной игры.

## Возможности

- Комнаты с кодом из 4 букв, до 6 игроков, переподключение после обрыва связи.
- 24 клетки Крысиных бегов: зарплата, возможность, рынок, безделушки, ребёнок, благотворительность, увольнение.
- Малые и крупные сделки (акции, недвижимость, бизнес), карточки рынка, продажа активов, банковские кредиты, банкротство.
- 3D-кубик, шаги фишек по клеткам, анимация вытягивания карточек (видят все игроки), подсветка клетки, конфетти при победе.
- Звуки (синтезируются в браузере, файлы не нужны), кнопка выключения 🔊/🔇.
- Кнопки быстрого выбора количества: `−max −100 −10 +10 +100 +max`, предупреждения о нехватке денег.
- Панель «🔍 Подробно»: доходы, расходы, активы и пассивы по статьям (для себя и для любого игрока по клику).
- Клик по клетке: описание, кто на ней стоит, галерея всех карточек колоды.
- Кнопка «📖 Правила» с кратким изложением правил.
- Чат партии и команды создателя комнаты (👑).
- Панели справа меняются по высоте перетаскиванием разделителей, раскладка подстраивается под окно.

## Быстрый старт

Нужен [Node.js](https://nodejs.org) 18+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`, введите имя и нажмите «Создать комнату». Друзья заходят по тому же адресу с кодом комнаты.
Порт можно поменять переменной окружения: `PORT=8080 npm start`.

Игра по интернету без хостинга: запустите сервер у себя и откройте туннель, например `cloudflared tunnel --url http://localhost:3000` или `ngrok http 3000`, ссылку отправьте друзьям.

## Как играть

1. Создатель комнаты делится кодом, игроки заходят, создатель нажимает «Начать игру».
2. Каждому выдаётся случайная профессия. Стартовые наличные равны получке плюс сбережениям.
3. В свой ход: бросить кубик, выполнить действие клетки, нажать «Завершить ход». Кредиты и погашение доступны в свой ход всегда.
4. **Победа:** пассивный доход стал больше общих расходов (проверяется после покупки, продажи и в конце хода).

Подробные правила: кнопка «📖 Правила» в игре.

### Что реализовано по правилам

| Правило | Как в игре |
|---|---|
| Получка | при попадании на клетку и при проходе, считается автоматически |
| Малые и крупные сделки | малые до $5 000 взноса, крупные от $6 000 |
| Рынок | продать актив можно только когда карточка рынка его называет, можно частями |
| Безделушки | обязательны, при нехватке денег автокредит кратно $1 000 |
| Ребёнок | максимум 3, растут расходы |
| Благотворительность | 10% дохода, 2 кубика на 3 хода |
| Увольнение | платишь расходы, пропуск 2 ходов |
| Кредит | кратно $1 000, 10% в месяц, гасится частями по $1 000 |
| Банкротство | активы за ½ взноса, пропуск 3 ходов, затем выбывание |

### Что упрощено или не реализовано

- **Нет Fast Track**: выход из Крысиных бегов сразу означает победу.
- Нет досрочного погашения ипотеки, автокредитов, карт и розничных долгов (гасятся только банковские кредиты).
- Нельзя продавать карточку возможности другим игрокам.
- Нет «аудитора» (расчёты делает сервер).

## Команды создателя комнаты

Вводятся в чат. Работают только у создателя (рядом с именем 👑), остальным в ответ приходит сообщение об ограничении. Имя можно писать началом (`/give Ва 500`).

| Команда | Действие |
|---|---|
| `/help` | список команд (виден только вам) |
| `/give Имя 1000` | выдать деньги, отрицательное число забирает |
| `/income Имя 500` | добавить пассивный доход в месяц |
| `/kids Имя 2` | задать число детей (0–3) |
| `/goto Имя 12` | переместить на клетку 1–24, без срабатывания клетки |
| `/dice 6` | следующий бросок выдаст это число |
| `/next` | передать ход следующему |
| `/win Имя` | объявить победителем |
| `/kick Имя` | исключить игрока |
| `/end` | завершить игру для всех |

Команды работают только после старта игры.

## Архитектура

**Сервер авторитетный.** Клиент только отправляет действия, а сервер проверяет их, меняет состояние комнаты и рассылает всем игрокам полное состояние (`state`). Комнаты хранятся в памяти процесса (`rooms` в `server.js`), базы данных нет.

### Сообщения клиент → сервер (`{a: ...}`)

| `a` | Параметры | Описание |
|---|---|---|
| `create` / `join` / `rejoin` | `name`, `room`, `id` | вход в комнату |
| `start` | | начать игру (только создатель) |
| `roll` | | бросить кубик |
| `draw` | `big` | выбрать малую или крупную сделку |
| `buy` | `n` | купить предложенное (акции: количество) |
| `pass` | | отказаться от сделки |
| `charity` | `yes` | согласиться или отказаться от пожертвования |
| `sell` | `n` | продать по карточке рынка (количество) |
| `loan` / `repay` | `amt` | взять или погасить кредит |
| `end` | | завершить ход |
| `chat` | `text` | сообщение или команда, если начинается с `/` |

### Сообщения сервер → клиент (`{t: ...}`)

`joined` (id, код комнаты, колоды карточек), `state` (всё состояние), `err` (ошибка, показывается всплывашкой), `sys` (личное сообщение в чат, например `/help`).

### Клиент

- `handle()` обрабатывает состояния по очереди (цепочка промисов): сначала анимация кубика, потом шаги фишки, потом карточка, потом отрисовка. Поэтому все игроки видят одинаковую последовательность.
- Размеры считаются от ширины поля (`--b`), поэтому всё масштабируется вместе с окном.
- `sessionStorage` хранит комнату и id игрока для переподключения, `localStorage` хранит высоты панелей и настройку звука.

## Как менять контент

Всё в начале `server.js`:

- **Профессии**: массив `PROFS` (и долги в `LIAB`).
- **Карточки сделок**: `SMALL` (малые), `BIG` (крупные).
- **Рынок**: `MARKET`, **безделушки**: `DOO`.
- **Поле**: массив `BOARD` (порядок клеток, число клеток должно быть 24 и менять нужно и в `public/index.html`).
- Новые карточки автоматически появляются в галерее колод.
- Недвижимость связывается с рынком через поле `key`: карточка рынка с тем же `key` позволяет продать такой объект.

## Размещение (хостинг)

Нужен хостинг, который запускает Node-процесс и пропускает WebSocket. Статические хостинги (GitHub Pages, обычный Vercel/Netlify) не подходят: бэкенду нужен постоянный процесс.

### Render (бесплатный тариф)

1. Залейте папку проекта в репозиторий на GitHub.
2. На [render.com](https://render.com): **New → Web Service**, выберите репозиторий.
3. Runtime: Node, **Build Command**: `npm install`, **Start Command**: `npm start`, тариф **Free**.
4. После деплоя откройте выданный адрес `https://....onrender.com`. Клиент сам использует `wss://`, настраивать ничего не нужно.

Ограничения бесплатного тарифа: сервис засыпает после 15 минут без запросов, а пробуждение занимает около минуты. Комнаты хранятся в памяти и пропадают при перезапуске. Во время игры WebSocket-сообщения не дают сервису заснуть.

### Другие варианты

- **Свой компьютер + туннель** (Cloudflare Tunnel, ngrok): бесплатно, без засыпания, пока включён компьютер.
- **VPS**: любой, где запускается Node (`npm start`, при желании под `pm2` и за nginx с поддержкой `Upgrade` для WebSocket).

## Идеи для развития

- Fast Track (двойные кубики, бизнесы, мечты) и победа по правилам настольной игры.
- Досрочное погашение долгов и продажа карточек возможностей другим игрокам.
- Сохранение комнат во внешнем хранилище, чтобы переживать перезапуски.
- Больше карточек и профессий, режим «играть по-настоящему» с реальными доходами и расходами.
